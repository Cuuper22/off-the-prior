# results/mechanism/analog: template or retrieval? (chaos family)

`scripts/analog_test.py` on the 344 chaos samples (`results/map/chaos`, regenerated byte-identically
on Colab), context 2048, horizon 128: oracle, method of analogues, seasonal template, and
Timestral 5M / 28M / 123M / 209M.

- `summary.csv`, `per_sample.csv`, `provenance.json`: all four sizes, run on the user's laptop
  GPU (RTX 3060 Laptop) from a code bundle of this repository (`git archive` of master; the
  bundle has no .git, so provenance shows an empty commit).
- `vm_5M_28M/`: the same test for 5M and 28M on the VM CPU.
- `parity_vm_cpu_vs_laptop_gpu.json` (`scripts/parity_check.py`): per-sample agreement of the
  two runs. Deterministic columns (oracle, analogues, template) are identical; Timestral's
  MASE differs by at most a few parts in 100,000 between CPU and GPU.
